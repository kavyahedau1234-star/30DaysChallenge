# Online Store Billing Calculator

A simple C program that calculates the final bill for a customer purchasing items from an online store. It uses conditional statements to decide the discount and delivery charge based on the customer type and delivery distance.

## Problem Statement

A student is purchasing items from an online store. The program reads:

- Purchase amount
- Customer type (1 = Student, 2 = Regular Customer)
- Delivery distance in kilometres

Based on these inputs, it determines the discount and delivery charge using conditional statements

## What Does This Program Do?

The program displays:

- Purchase Amount
- Discount Amount
- Amount After Discount
- Delivery Charge
- Final Payable Amount

## Built With

- **C Language**
- printf() and scanf() for input and output
- if, else if , else conditional statements
- Basic arithmetic operations
